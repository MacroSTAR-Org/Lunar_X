# 群聊语录（quote）

收录群友的金句，随时随机翻出来。**仅支持群聊**，私聊会提示不可用。

## 指令

| 指令 | 说明 |
|---|---|
| `$收录 <内容>` | 收录一句话 |
| `$收录 <分类> <内容>` | 带分类收录，如 `$收录 沙雕 今天又帅了` |
| `$收录`（引用消息时） | **引用/回复一条消息后直接发 `$收录`**，收录被引用的内容 |
| `$语录` | 随机播放一条 |
| `$语录 <分类>` | 随机播放该分类的一条 |
| `$语录列表 [分类]` | 查看最近的语录（带编号） |
| `$语录搜索 <关键词>` | 按内容搜索 |
| `$删除语录 <编号>` | 删除，**仅管理员** |

分类是可选的：`$收录 沙雕 今天又帅了` 里，第一段「沙雕」不超过「分类名最大字数」才会被当成分类，否则整句都算内容。

## 配置项

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| 语录最大字数 | 整数 | 200 | 超过就拒绝收录 |
| 分类名最大字数 | 整数 | 6 | 决定第一段算不算分类 |
| 列表/搜索返回条数 | 整数 | 20 | |
| 随机抽取池大小 | 整数 | 500 | 从最近这么多条里随机，越大越不容易重复但查询越慢 |

## 数据

SQLite，位置 `data/quote/quotes.db`，表结构：

```sql
quotes(id, group_id, user_id, category, content, ts)
```

语录按群隔离，A 群的 `$语录` 不会翻出 B 群的内容；`$删除语录` 也只能删本群的。

> **升级说明**：老版本的数据库在 `data/quotes.db`。插件首次启动会自动搬到 `data/quote/quotes.db`，已有语录不会丢。搬完旧文件就不在了，这是正常的。

## 关于引用收录

引用模式优先读 Milky 协议 reply 段自带的内容（Milky 1.2+ 会把被引用消息一并带过来），协议端没带就退回调 `get_message` 拉取。

**只收录文本**，图片、表情这些非文本段会被忽略；如果被引用的消息纯图片，会提示用法。
