# 工具箱（tools）

三块功能打包在一起：定时提醒、群管理、消息持久化与检索。

## 指令

### 定时提醒
| 指令 | 说明 |
|---|---|
| `$定时 <时长或时间> <内容>` | 如 `$定时 10分钟 喝水`、`$定时 09:00 开会` |
| `$定时列表` | 查看本群未到期的任务 |
| `$定时取消 <编号>` | 取消 |

任务落库，**框架重启后会自动恢复**未到期的任务。

### 群管理（需管理员权限）
| 指令 | 说明 |
|---|---|
| `$禁言 @某人 <时长>` | 如 `$禁言 @张三 10分钟` |
| `$解禁 @某人` | |
| `$踢人 @某人` | |
| `$全体禁言` / `$取消全体禁言` | |
| `$公告 <内容>` | 发群公告 |

权限走框架的 `manager` 级别，名单在 WebUI 的**设置 → 用户**里配。

### 消息检索
| 指令 | 说明 |
|---|---|
| `$历史消息 <关键词> [条数]` | 搜索本群消息记录 |
| `$群消息统计` | 近 7 天消息量 |

## 配置项

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| 记录群消息 | 开关 | 开 | **关掉后检索功能就没有新数据了** |
| 记录范围（群白名单） | 群号列表 | 空 | 留空 = 所有群 |
| 记录私聊消息 | 开关 | **关** | 私聊内容敏感，默认不记录 |
| 历史消息搜索上限 | 整数 | 50 | 单次最多返回多少条 |

> 早期版本**无条件记录每一条消息**且没有开关。现在默认仍记录群消息（保持行为一致），但你可以按群收窄或整个关掉。

## 数据

SQLite，位置 `data/tools/tools.db`：

```sql
messages(id, ts, scene, group_id, user_id, text)   -- 正文截断到 500 字
scheduled(id, group_id, user_id, content, due_ts, done)
```

> **升级说明**：老版本在 `data/tools.db`，首次启动自动搬到 `data/tools/tools.db`，数据不丢。

## 文件结构

```
tools/
  setup.py       入口：分发指令、消息入库
  scheduler.py   定时任务
  group_admin.py 群管理
  store.py       SQLite 读写
```

这是**目录插件引用自己子模块**的例子：`from store import save_message` 这种顶层绝对导入。框架在加载期间会把插件目录挂到 `sys.path`，加载完就摘掉，所以不同插件里的同名文件（比如各自都有 `store.py`）不会互相串。
