# 连通性测试（ping）

最小的示例插件，用来确认机器人还活着。

## 指令

| 指令 | 说明 |
|---|---|
| `$ping` | 回复 `pong 🏓` + 一个表情 |

群聊里会 @ 发送者，私聊则直接回。

## 配置

无。

## 它演示了什么

这是**写插件的最小样板**，一共十几行：

- `TRIGGHT_KEYWORD = 'ping'` —— 非 `'Any'` 的触发词，只有 `$ping` 才会调到它
- `PLT_ST = 10` —— 优先级，数字越小越先执行
- 用 `bot.msg.at()` / `bot.msg.text()` / `bot.msg.face()` 拼多段消息，框架会自动映射成协议端的格式（Milky 的 mention / face 段）
- `return True` 阻断后续插件继续处理

照着它改是上手最快的方式。
