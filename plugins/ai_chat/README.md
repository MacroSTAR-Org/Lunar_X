# AI 对话（ai_chat）

接入任意 OpenAI 兼容接口（DeepSeek / OpenAI / 各类中转），做一个会旁听、有记忆、
知道什么时机开口的"赛博群友"。

## 两种运行模式

| 模式 | 行为 |
|---|---|
| **agent**（默认） | 多智能体管线：旁听群聊 → 规划器判断要不要回 → 回复器生成 → 风格层发送 |
| classic | 原始单模型直答：只被动应答，无旁听无记忆。随时可切回 |

### agent 模式怎么工作

1. **旁听**：每条群消息进内存时间线（只存内存，重启即清，绝不落盘）。
2. **直接触发**：被 @、被叫名字、`$ai` 命令、私聊——零延迟直接回复，不经过规划器。
3. **防抖审查**：群里安静 20 秒（或攒够 12 条、最长等 120 秒）后，把这批消息交给
   **规划器**（建议配便宜模型）判断：回复 / 看图 / 插话 / 忽略。规划器上下文不够时
   会自己用工具查更早的记录。
4. **回复器**（主模型）带上群聊上下文 + 长期记忆 + 规划器给的理由生成回复。
5. **风格层**（默认关）：打字延迟、按标点分段、偶尔带表情，像人打字而不是文档。

## 触发方式

| 方式 | 条件 | 例子 |
|---|---|---|
| 命令 | 总是可用 | `$ai 今天天气怎么样` |
| 名字唤醒 | 群聊 + 消息以唤醒词**开头** | `小月 今天天气怎么样` |
| 被间接提及 | agent 模式 + 消息**中间**出现唤醒词 → 按概率接话 | `帮我看看 小月 在不在` |
| @ 唤醒 | 群聊 + 开启「私聊直连 / @ 唤醒」 | `@机器人 今天天气怎么样` |
| 私聊直连 | 私聊 + 开启「私聊直连 / @ 唤醒」 | 直接发消息 |
| 主动插话 | 仅 `event+timer` 档，有每日上限与静音时段保护 | （无需触发） |

## 记忆与隐私（重要）

- **旁听上下文只存内存**：重启即清，不写磁盘、不上传，且受群白名单约束。
- **长期记忆默认关闭**：开启「长期记忆（落盘）」后，才会把从对话中抽取的
  用户事实（如"在读研究生"）写入 `data/ai_chat/memory.db`。
- `$ai 忘了我`：删除 AI 关于你的全部长期记忆。
- 记忆保留天数默认 90 天，到期自动清理。

## 图片理解

「图片理解」默认关闭。开启后群友发图，机器人可以看懂并接话。
需要支持 vision 的模型（deepseek-chat 不支持；可用 qwen-vl、gpt-4o-mini 等，
在「看图模型」里单独配置）。

## 配置项

在 WebUI 的**插件管理 → ai_chat → 配置**里改，落盘在本目录的 `config.json`。
保存即热生效，无需重启。

### 基础

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| 启用 AI 对话 | 开关 | 关 | 关闭后完全不走 AI 逻辑 |
| 运行模式 | 选择 | agent | agent=多智能体 / classic=单模型直答 |
| API 地址 | 文本 | `https://api.deepseek.com` | **不要带** `/v1/chat/completions` 路径 |
| API Key | 密钥 | 空 | |
| 模型 | 文本 | `deepseek-chat` | 主模型，回复器默认用它 |
| Temperature | 小数 | 1.0 | 回复发散度 |
| Max Tokens | 整数 | 2048 | 单次回复上限 |
| 历史消息轮数 | 整数 | 10 | 个人会话保留几轮 |
| 私聊直连 / @ 唤醒 | 开关 | 关 | 开了之后私聊任意消息、群里 @ 都会触发 |
| 群白名单 | QQ 群号列表 | 空 | **留空 = 不限制**；旁听也受它约束 |
| 用户白名单 | QQ 号列表 | 空 | 留空 = 不限制 |
| agent 故障降级 | 开关 | 开 | 管线失败自动回退单模型直答 |

### 旁听与规划器（agent 模式）

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 旁听群聊 | 开 | 只存内存；关掉后机器人"失聪" |
| 时间线容量 / 保留 | 30 条 / 120 分钟 | 每群维护的旁听窗口大小 |
| 规划器模型 | 空=主模型 | **建议配便宜快的模型**，判定不需要聪明 |
| 防抖静默期 / 批量条数 / 最长等待 | 20s / 12 条 / 120s | 三个触发审查的条件 |
| 启用规划器 | 开 | 关掉后只剩直接触发 |

### 画像与记忆

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 长期记忆（落盘） | **关** | 开启才写库；`$ai 忘了我` 可清 |
| 记忆抽取模型 | 空=主模型 | 后台异步抽取，建议配便宜模型 |
| 记忆保留天数 / 每人上限 | 90 / 100 | |

### 拟人化

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 拟人化风格层 | 关 | 打字延迟 + 分段发送 + 口语化约束 |
| 表情概率 | 0 | 每次回复随机带小黄脸的概率 |
| 被戳回戳 / 撤回调侃 / 入群欢迎 | 关 | 事件反应，各有独立开关与冷却 |
| 主动行为档位 | **event** | off=完全被动；event=事件反应+被间接提及按概率接话；event+timer=允许低频主动插话 |
| 被间接提及的接话概率 | 0.3 | 每群 10 分钟冷却 |
| 静音时段 | 01:00-08:00 | 此时段不主动插话 |

### 图片理解

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 图片理解 | 关 | 需 vision 模型 |
| 看图模型 | 空=主模型 | 必须支持 vision |
| 单次最多几张 / 单图上限 | 2 张 / 5MB | 超限跳过，失败降级纯文本 |

## 成本说明

- 旁听本身**零成本**（纯内存记录）；成本发生在规划审查与回复。
- 规划器 + 回复器分开配模型：判定用便宜的，说话用好的，一天下来比全用主模型省得多。
- 全部功能都可以单独关闭；classic 模式下行为与旧版完全一致。

## 常见问题

**回复「AI 未配置」**：API 地址或 Key 是空的。

**群里发消息没反应**：按顺序查——插件是否启用、群是否在白名单里、是否以唤醒词**开头**
（中间出现要走概率接话）、防抖静默期是否还没到。

**感觉它话太多 / 太少**：调「被间接提及的接话概率」和「主动行为档位」；
event+timer 档有每日 3 次/群的上限和静音时段。

**重启后它不记得群里聊过什么**：旁听在内存里，这是有意设计（隐私优先）。
跨重启的只有显式开启的长期记忆。

## 依赖

`aiohttp`（框架自带，无需额外安装）。
