# AI 对话（ai_chat）

接入任意 OpenAI 兼容接口（DeepSeek / OpenAI / 各类中转），在群里和私聊里做 AI 助手。

## 触发方式

四种，可以叠加：

| 方式 | 条件 | 例子 |
|---|---|---|
| 命令 | 总是可用 | `$ai 今天天气怎么样` |
| 名字唤醒 | 群聊 + 开启「启用名字唤醒」 | `小月 今天天气怎么样` |
| @ 唤醒 | 群聊 + 开启「私聊直连 / @ 唤醒」 | `@机器人 今天天气怎么样` |
| 私聊直连 | 私聊 + 开启「私聊直连 / @ 唤醒」 | 直接发消息 |

## 配置项

在 WebUI 的**插件管理 → ai_chat → 配置**里改，落盘在本目录的 `config.json`。

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| 启用 AI 对话 | 开关 | 关 | 关闭后完全不走 AI 逻辑 |
| API 地址 | 文本 | `https://api.deepseek.com` | **不要带** `/v1/chat/completions` 路径 |
| API Key | 密钥 | 空 | |
| 模型 | 文本 | `deepseek-chat` | 需与 API 地址匹配 |
| Temperature | 小数 | 1.0 | 0~2，越大越发散。闲聊 1.0~1.3，要稳定输出用 0.3~0.7 |
| Max Tokens | 整数 | 2048 | 单次回复上限 |
| 历史消息轮数 | 整数 | 10 | 每个会话保留几轮上下文，越大越贵 |
| 私聊直连 / @ 唤醒 | 开关 | 关 | 开了之后私聊任意消息都会触发，慎开 |
| 群白名单 | QQ 群号列表 | 空 | **留空 = 不限制**，填了则只有列表内的群能用 |
| 用户白名单 | QQ 号列表 | 空 | 同上 |
| 系统提示词 | 多行文本 | 见默认值 | 人格设定为空时的兜底 |
| 启用名字唤醒 | 开关 | 开 | |
| 唤醒词 | 每行一个 | 小月 / 月月 | 按长度降序匹配，短词不会吃掉长词 |
| 人格设定 | 多行文本 | 空 | **优先级高于系统提示词** |

## 会话上下文

按 `群号:QQ号`（群聊）或 `QQ号`（私聊）分别保存，互不串台。

**上下文只存在内存里，重启即清空**——这是有意为之，避免把聊天记录落盘。需要持久化的话得自己改。

## 常见问题

**回复「AI 未配置」**：API 地址或 Key 是空的。

**回复「401」**：Key 不对，或者 Key 和 API 地址不是同一家的。

**群里发消息没反应**：按顺序查——插件是否启用、群是否在白名单里、消息是不是以唤醒词**开头**（唤醒词必须在最前面）。

**想让它回应所有消息**：开「私聊直连 / @ 唤醒」并清空唤醒词。注意这会让它回应群里每一条消息，很吵也很费钱。

## 依赖

`aiohttp`（框架自带，无需额外安装）。
